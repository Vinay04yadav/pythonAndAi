# Python & AI Notes

This repository is where I collect notes and examples as I learn Python and artificial intelligence.

## Repository contents

### `OOPS_In_Python/`

This folder contains Python examples and notes on object-oriented programming:

- [`01_SimpleClass.py`](./OOPS_In_Python/01_SimpleClass.py) — Defining simple classes, creating objects, and checking an object's type.
- [`02_NameSpace.py`](./OOPS_In_Python/02_NameSpace.py) — Class and instance attributes, object namespaces, and adding attributes to objects.
- [`03_AttributeShadowing.py`](./OOPS_In_Python/03_AttributeShadowing.py) — Attribute shadowing: overriding a class attribute on an instance and deleting the instance attribute to reveal the class value again.
- [`04_SelfArgs.py`](./OOPS_In_Python/04_SelfArgs.py) — Instance methods, the purpose of `self`, and calling a method through an object or class.
- [`05_init_objects.py`](./OOPS_In_Python/05_init_objects.py) — The `__init__` constructor and initializing different objects with their own values.
- [`06_inheritance_composition.py`](./OOPS_In_Python/06_inheritance_composition.py) — Inheritance and composition, with examples of combining both patterns.

More notes and examples will be added as I continue learning.
